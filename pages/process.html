modules

  • Global CSS, theme token, layout shell
  • Header, screen containers, modal/toast slots
  • External scripts болон app bootstrap include

  • Global state object, localStorage load/save
  • goTo router, renderAppScreen dispatcher
  • Auth guard, AI search, schedule confirm, modal actions

  • Home, results, property, schedule, saved, news screens
  • Map pins, heatmap, full-map overlay, draw zone
  • AI chat surface болон UI row/card builders

  • Lightbox, compare, reviews, detailed stats modal

  • Home Leaflet map integration

  • LISTINGS, AGENTS, DISTRICTS, DISTRICT_ZONES
  • SAVED_SEARCHES, VIEWINGS, BANKS, POI datasets
  • Mock product data болон helper metadata

  • 6 алхамт interests wizard
  • computeMatchScore болон matchedListings
  • Dismiss/restore, upgrade modal, personalized feed

5. Decision points ба салаалсан урсгал

Project дотор хэрэглэгчийн эрх, хайлтын үр дүн, map interaction, зар нэмэх зэрэг хэд хэдэн шийдвэрийн цэг байна.

logic
?

Нэвтэрсэн үү?

profile, activity, saved, alerts, rental-mgmt, list-property, schedule screen-үүд protected. Үгүй бол auth руу очно.

?

AI query байна уу?

Байвал AI extracted chips болон filter state шинэчлэгдэж, results context өөрчлөгдөнө.

?

Дүүрэг сонгосон уу?

Map polygon selected бол zone-summary, district stats, dimmed zones, filtered listings идэвхжинэ.

?

Full map нээгдсэн үү?

map-fs-overlay гарч, sidebar жагсаалт + map stage + compact AI launcher зэрэг тусгай UX ажиллана.

?

Result хоосон уу?

Empty state гарч, clearAllFilters эсвэл AI дахин хайлт санал болгоно.

?

Зар хадгалсан уу?

SAVED_IDS болон SAVED_SEARCHES tabs дээр хадгалсан зар, хайлт, alert flow гарна.

?

Зар оруулах mode?

listPropMode нь rent/sale байж, price/deposit/mortgage fields өөрөөр харагдана.

?

Interests profile бий юу?

Байвал match score бүхий personalized feed, байхгүй бол setup wizard эхэлнэ.
